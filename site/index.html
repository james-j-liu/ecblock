ECBLock — ECB Governing Council Hawkishness

An LLM pairwise tournament scoring euro-area monetary-policy communication on a hawkish–dovish spectrum. 0 = neutral; positive = more hawkish (tighter), negative = more dovish. Method adapted from FedLock. Scores reflect LLM judgment, not official characterizations.
